# IP Hunter

IP Hunter is a Flask-based web application designed for educational purposes to demonstrate how visitor information can be collected and analyzed through a web browser.


## 📋 Overview

This project showcases various tracking techniques commonly used on the web, including:
- IP address collection
- Browser fingerprinting
- Device information gathering
- Network details collection
- User behavior tracking

**⚠️ IMPORTANT: This project is for educational purposes only. Always use such tools ethically and responsibly, with proper consent from users, and in compliance with privacy laws such as GDPR, CCPA, etc.**

## 🚀 Features

- **Visitor Tracking**: Captures detailed information about visitors
- **Admin Dashboard**: View and analyze collected data
- **Detailed Reports**: In-depth analysis of each visitor
- **Multiple Tracking Methods**:
  - Visible page tracking
  - Invisible pixel tracking
  - JavaScript-based tracking
- **Comprehensive Data Collection**:
  - IP address information
  - Browser details
  - Device specifications
  - Network information
  - Screen resolution
  - Timezone data
  - Feature support

# IP Hunter

O IP Hunter é um aplicativo web baseado em Flask, desenvolvido para fins educacionais, que demonstra como as informações dos visitantes podem ser coletadas e analisadas por meio de um navegador web.


## 📋 Visão geral

Este projeto apresenta diversas técnicas de rastreamento comumente utilizadas na web, incluindo:
- Coleta de endereços IP
- Impressão digital do navegador
- Coleta de informações do dispositivo
- Coleta de detalhes da rede
- Rastreamento do comportamento do usuário

**⚠️ IMPORTANTE: Este projeto é apenas para fins educacionais. Sempre utilize essas ferramentas de forma ética e responsável, com o devido consentimento dos usuários e em conformidade com as leis de privacidade, como GDPR, CCPA, etc.**

## 🚀 Recursos

- **Rastreamento de Visitantes**: Coleta informações detalhadas sobre os visitantes
- **Painel do Administrador**: Visualiza e analisa os dados coletados
- **Relatórios Detalhados**: Análise aprofundada de cada visitante
- **Múltiplos Métodos de Rastreamento**:
- Rastreamento de página visível
- Rastreamento de pixel invisível
- Rastreamento baseado em JavaScript
- **Coleta Abrangente de Dados**:
- Informações de endereço IP
- Detalhes do navegador
- Especificações do dispositivo
- Informações de rede
- Resolução da tela
- Dados de fuso horário
- Suporte a recursos
